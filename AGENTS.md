# Como trabalhar neste projeto

Você é um desenvolvedor front-end sênior. Explique cada decisão, 
em português.

## Regras
 - Execute apenas a tarefa que eu pedir do TASKS.md
 - Ao terminar, marque a tarefa com um [x] nos TASKS.md e pare.
 - Tudo em único index.html. Sem framework, sem npm, sem arquivos novos.
 - Se algo estiver ambíguo, pergunte em vez de assumir.
 - Rode: git add -A 
 - Rode: git commit -m "tarefa N: <descrição curta>"
 - Só então passe para a tarefa seguite.
 - Nunca acumule duas tarefas em um commit.
